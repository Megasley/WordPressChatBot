# WordPress AI Chatbot with DeepSeek API

An AI-powered chatbot for WordPress websites that uses DeepSeek API and custom document data to provide conversational responses to user queries.

## Features

- **AI Chat Widget**: Clean, modern floating chat interface for your WordPress site
- **Custom Knowledge Base**: Train the chatbot with your own documents (.txt or .md files)
- **Vector Similarity Search**: Uses FAISS to find relevant information from your documents
- **DeepSeek API Integration**: Generates natural, conversational responses
- **Conversation Memory**: Maintains context across multiple exchanges
- **Feedback System**: Users can rate responses to help improve answers
- **Simple WordPress Integration**: Just add a single script tag to your site
